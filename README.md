## 一、程式用途
本程式用來整理「桌遊體驗」與「電影欣賞」兩場活動的原始報名文字，並計算各場參加者名單、人數、人次與應收費用。透過字串清理與 tuple、list、set、dict 四種 Python 資料型別的搭配操作，示範在不寫迴圈、條件分支與自訂函式的情況下完成資料處理與摘要輸出：

tuple（activity_names）：保存固定的兩個活動名稱，供讀取名稱與查詢費用。

list：先保留原始字串（board_raw、movie_raw），再建立移除半形空白、轉小寫並依逗號切分後的串列，保留原始順序與重複報名紀錄；同時也用於排序後名單與切片取得前兩位通知名單（[:2]）。

set：將兩場整理後的串列轉為集合以去除同一場內的重複報名，並透過交集（&）、聯集（|）與雙向差集（-）比較共同參加者、全部參加者、只參加桌遊者與只參加電影者。

dict（unit_fees、summary）：以活動名稱查詢每人單價（桌遊 120 元、電影 80 元），並將各類人數、人次與應收金額集中在摘要字典中計算與輸出。
